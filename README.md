## 🚀 セットアップ

### Git LFSの初期設定

このプロジェクトでは画像ファイルをGit LFSで管理しています。

```bash
# Git LFSをインストール（初回のみ）
git lfs install

# リポジトリをクローン
git clone [repository-url]
cd profile_site

# LFSファイルを取得
git lfs pull
```

### サイトの起動

```bash
# srcディレクトリに移動
cd src

# ブラウザでindex.htmlを開く
open index.html  # macOS
# または
start index.html  # Windows
```
